Where to Play No Filter Fighters

No Filter Fighters is a free fan game. The copy you want is the one published by Trey2k23 (TDHampton Productions) on itch.io. This site does not host the game. Other pages and “sequel” listings exist; treat the itch.io project as the source of truth for the current build.

Option 1: Play in the browser

The game runs directly in a desktop or mobile browser with no install. This is the fastest way to try it, and the version the developer keeps up to date.

  • Best for: a first try, or playing on a machine you do not want to install things on.
  • Watch out for: the first load is slow. Keep the tab in the foreground until the title screen appears.

Open the itch.io page →

Option 2: Download for Windows, Linux or Steam Deck

The same itch.io page hosts zip packages. Extract the whole folder; do not run a random installer from a search result.

  1. Download the zip for your system and extract the complete folder.
  2. On Windows, run Martin No Filter Fighters.exe. If Windows shows its protected-PC screen, the creator's instructions are More info, then Run anyway.
  3. If the window is black or the graphics glitch, run Launch - Compatibility Mode.bat from the same folder.
  4. F11 or Alt+Enter toggles fullscreen. Settings carry over when you update.
  • Best for: slow connections, repeated play, offline use.
  • Watch out for: download only from the creator's itch.io page. Fan games get re-uploaded to random file hosts constantly, and those copies are not checked by anyone.

Before you open any download

Fan games are not signed or reviewed the way store apps are, so a little caution is reasonable:

  1. Use the itch.io project, not a search-result download button. Search for a fan game and you will find aggregator sites that wrap the file in an installer.
  2. Expect a zip you extract, not a setup wizard. If a download offers you an .exe installer with toolbars or “extra software”, it is not the original build — close it.
  3. Ignore lookalike listings. Comment threads already point at other games using a similar name. If the author is not Trey2k23, it is a different project.
  4. Check the version number. The current listing as of this page is v13.2. Older copies stay up around the web.

Frequently asked questions

Is it on Steam or mobile stores?

No. It is a free fan project distributed through itch.io, not a commercial release, so it is not on Steam, the App Store or Google Play. A Steam Deck can still run the Linux zip.

Do I need an account?

Not to play in the browser. itch.io may ask you to sign in to comment, follow the project or rate it, but playing does not require it.

Does it work on a phone or tablet?

Yes. Touch controls appear in landscape. A desktop keyboard is still the more comfortable way to play a fighter.

Is it still being updated?

Yes. Numbered builds are still landing — v12.9 added Bruh-Man and the PC zips; v13.2 added Bob from Marketing. Check the itch.io page for the current version rather than assuming a number you read somewhere else is current.

Is this the official site?

No. This is an unofficial fan guide. We do not host the game files and we are not connected to the developer. The itch.io page is the authoritative source.
